# ShareGPT4V (COCO subset, eval-only)

This task evaluates image-captioning models against the highly-detailed
ShareGPT4V references for the COCO 2017 subset.

ShareGPT4V (Chen et al., ECCV 2024) is a large-scale, training-oriented
multimodal dataset whose captions were generated by GPT-4V. The official
release ships only the JSON caption files (`Lin-Chen/ShareGPT4V`); the
images themselves come from COCO 2017, SAM, LLaVA and other public
sources. Here we re-purpose the cleanest slice — the COCO entries — as an
evaluation benchmark.

## Dataset construction

We host a pre-built parquet at
[`Icey444/ShareGPT4V-COCO-eval`](https://huggingface.co/datasets/Icey444/ShareGPT4V-COCO-eval).
The build procedure is reproducible via
[`build_eval_parquet.py`](./build_eval_parquet.py):

1. Download `sharegpt4v_instruct_gpt4-vision_cap100k.json` from
   `Lin-Chen/ShareGPT4V` (100K rows).
2. Keep entries whose `image` path starts with `coco/` (~50K COCO 2017
   images).
3. For 500 of these images, fetch the corresponding JPG directly from the
   public `images.cocodataset.org` mirror.
4. The ShareGPT4V reference caption is the value of
   `conversations[1]["value"]` (the GPT response).
5. Persist as a single parquet with columns `image` (PIL), `image_id`
   (string) and `caption` (string).

The task uses one ShareGPT4V reference per image and reports the same five
COCO caption metrics (BLEU-1/2/3/4, METEOR, ROUGE-L, CIDEr).

The model prompt is `"Describe the image in detail."` because ShareGPT4V
references are detail-heavy.
